## data-model — 2026-11-20
What: phase 1 data model. Frozen pydantic entities (Domain, IPAddress, ASN, Certificate, Technology, ArchivedURL) with canonical `type:value` ids (IDNA fqdn via scope.normalize_domain, compressed IP, bare ASN, lowercase sha256; cert SANs in the same IDNA form, wildcards kept). Deep review: hide_input_in_errors (secrets were echoed in ValidationError text), generic scrub (issuer/path emails leaked), Unicode/%40 emails. Security pass: email regex was quadratic (103 s on a 60 kB string) -> RFC length caps (0.26 s).

## collection-engine — 2026-11-21
What: phase 2 collection plumbing. `collect/cache.py` SQLite TTL cache (key = source + logical query/URL/non-secret params as JSON, secret params never stored, stale rows purged on open). `collect/ratelimit.py` per-source token bucket (lock per bucket, conservative 1 req/s default for undeclared sources, every retry spends a token). `collect/http.py` the single choke point of outgoing traffic: refuses target hosts (any name under a scope entry, expired/restricted included) and IP literals, never follows redirects, honest `SurfaceMap/<version>` UA, retries 429/5xx/transport with backoff + capped Retry-After, caches 2xx only; secret params never reach the cache key, error text, exception context or the httpx INFO log (silenced). `plugins/base.py` Plugin Protocol (explicit `runs_out_of_scope` policy flag, `applies_to` e.g. scope-root-only, `enabled(settings)`), PluginBase defaults, ScopeView (scope date pinned per run, memoized), PluginRegistry (slug names, `surfacemap` reserved, kinds derived from the Entity union) + `default_registry()` factory. `collect/engine.py` breadth-first waves: `scope.require(seed)` before any plugin; per-entity reach RESOLVE_ONLY < FULL (domains from scope, other entities from the nodes pointing at them in the same observation, fail-closed for endpoint-only parents); expansion tracked apart from reach; an out-of-scope subject only expands its CNAME chain; engine stamps `Domain.in_scope` and reads the next wave from redacted ids; bounds on depth, work items, per-call timeout, concurrency; failures logged by exception type only (PassiveViolationError at ERROR); structural HAS_SUBDOMAIN edges from source `surfacemap`.
Key files/commits: 3b4328a..1230761 on crew/batch-b (`src/surfacemap/collect/`, `src/surfacemap/plugins/base.py`; outside the Zone, minimal: `pyproject.toml` deps httpx/idna/respx/pytest-asyncio + asyncio_mode, `plugins/__init__.py`). Architect persona shaped the contract (Protocol, applies_to, waves, reach levels, pinned date). Security hook findings fixed: IDN host compared in Unicode vs punycode (raw_host), IDNA 2003 vs 2008 spelling bypass of the target guard (all spellings tried), parent-reach fail-open. Deep review fixed: CDN IP enriched via multi-hop resolver answers (I2), node recorded but never resolved (I1), cache key ignoring params (I3), redaction changing ids crashed the run (KeyError), out-of-scope NS/MX fan-out. Simplify: one reach assessment per observation (parents index), inlined retry loop.
Follow-ups: (1) `scope.normalize_domain` uses IDNA 2003 while httpx uses 2008: canonicalize on UTS46 in scope.py (outside zone) so a plugin emitting `xn--` 2008 spellings is not stamped out of scope; (2) `SurfaceGraph.merge` should return the redacted observation so the engine stops redacting twice (builder.py); (3) derive `in_scope` only from scope at merge time (models/builder); (4) 429 should penalize the whole source bucket, and fail rather than retry before a Retry-After above the 60 s cap; (5) bind each plugin's context to its name (cache/limiter namespace) and add an optional `rate_limit` attribute to the Protocol; (6) limiter wait counts in `plugin_timeout` and holds a concurrency slot; (7) SQLite cache is sync on the event loop, `check_same_thread`, one fsync per set (WAL / to_thread); (8) raw RDAP/WHOIS bodies are cached unredacted in the gitignored `.cache/`: user decision pending (redact before caching vs short TTL); (9) passive-plugins.md impact for the manager: crtsh/rdap/whois apex-only via `applies_to`, dns plugin may return the whole CNAME chain in one observation, architect suggests spf/dmarc (parsing of TXT records) and dorks (no entities) run outside the engine.
Tests: none — risky zones (scope, passive-only, secrets) touched but fully covered by automated offline tests, mutation-checked on the guards: tests/test_collect_cache.py, test_collect_ratelimit.py, test_collect_http.py, test_plugins_base.py, test_collect_engine.py (271 tests, 99 % coverage)
